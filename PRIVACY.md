# Политика конфиденциальности · Univer · КазНУ (Android)

Действует с версии **2.0** (29 октября 2026).

Приложение является неофициальным клиентом сайта [Univer КазНУ](https://univer.kaznu.kz/): оно открывает сайт во встроенном WebView, сохраняет вход и делает страницы удобными для телефона. Приложение не связано с КазНУ им. аль-Фараби и не имеет собственного сервера.

## Какие данные обрабатываются

| Данные | Где хранятся | Куда передаются |
|---|---|---|
| Логин и пароль Univer | Только на телефоне, в файле, зашифрованном AES-GCM ключом Android Keystore (при включённом PIN-коде также ключом из PIN) | Только на `https://univer.kaznu.kz` в штатную форму входа сайта |
| Cookies и данные сайта (сессия, настройки страниц; копия главной «Бакалавра»: пары этой и начала следующей недели, итоги по предметам, последние заявки и СРО этой недели — текстом, для вашего аккаунта и языка; номера файлов УМКД, уже виденных на странице предмета, чтобы отметить новые; для вашего аккаунта также: какой силлабус ваш и списки силлабусов предметов, названия тем и СРО из силлабусов и прочитанные недели расписания, задания дистанционных курсов, число неотвеченных анкет) | Хранилище WebView приложения | Только сайту Univer и СДО Moodle КазНУ (`dl.kaznu.kz`, `dl.kaznu.edu.kz`) при входе через Univer |
| Cookies и входы сайтов из окна ссылок | Отдельный профиль WebView приложения | Только тем сайтам, на ссылку которых вы нажали; Univer и Moodle их не получают |
| Скачанные файлы | Папка «Загрузки» телефона и список загрузок приложения | Никуда |
| Отчёт об успеваемости (PDF или PNG), расписание двух недель (.ics или PNG) | Временная папка приложения; удаляется при выходе, а если ему больше часа, то при следующем запуске или новом отчёте | Только приложению, которое вы выбрали в окне «Поделиться», или службе печати |
| Сохранённая неделя расписания и соседняя с ней, чётная или нечётная (предметы, время, аудитории, преподаватели) | Файл в папке приложения без резервной копии; удаляется при выходе из аккаунта | Никуда. Её показывают экран ошибки сети (пары на день), экран «Расписание без сети», виджет «Пары на сегодня» и напоминания о парах; с PIN-кодом виджет и напоминания не называют предмет. Пока сайт открыт в приложении, расписание читается с Univer раз в день, чтобы виджет знал текущую неделю |
| Последние итоги журнала (предметы и баллы, которые вы видели в журнале или Кабинете) | Файл в папке приложения без резервной копии; заменяется при каждом просмотре журнала, удаляется при выходе из аккаунта | Никуда. Их показывает экран ошибки сети, когда сайт не открывается; пока они на экране, снимки экрана закрыты |
| Расписание экзаменов и рубежного контроля (предмет, время, аудитория) | Файл в папке приложения без резервной копии; удаляется при выходе из аккаунта | Никуда. Ближайшие показывает экран ошибки сети; по нему приходят напоминания накануне и перед началом, если включены напоминания; с PIN-кодом напоминание не называет предмет |
| Цель в журнале и метки «новое» | Хранилище WebView приложения | Никуда |
| Итоги журнала для уведомлений о новых оценках (только если уведомления включены) | Файл в папке приложения без резервной копии; удаляется при выключении уведомлений и при выходе из аккаунта | Никуда. Сама проверка отправляет на `https://univer.kaznu.kz` один GET журнала с cookies текущей сессии, без пароля и без форм. Если сайт в ответ обновит cookie сессии, приложение сохранит его, как браузер, поэтому проверка может продлить сессию на сайте |
| Событие «В календарь» (название, время, аудитория) | Приложение его не хранит | Приложению календаря, которое откроется по кнопке. Дальше событие хранит календарь и может синхронизировать его со своим аккаунтом |
| Настройки (язык, размер текста, плитки, PIN-код) | Настройки приложения на телефоне | Никуда |
| Проверка обновлений (найденная версия, время проверки) | Настройки приложения на телефоне | На `github.com` уходит обычный запрос без логина и cookies: GitHub видит IP-адрес и название приложения |

- Приложение **не** собирает аналитику, не показывает рекламу, не использует сторонние SDK отслеживания и не отправляет данные разработчику.
- Сайт Univer подключает на своих страницах Google Analytics. Приложение этот счётчик не загружает: в окне сайта и в окне документов и Moodle запросы к Google Analytics и Google Tag Manager не уходят в сеть, поэтому Google Analytics не получает, какие страницы вы открываете. Окно ссылок их не блокирует. Другие сторонние сервисы страницы могут подключать сами, приложение их не добавляет. Сторонние cookies во WebView отключены.
- Сведения о заданиях дистанционных курсов приложение читает с тех же страниц Univer, что открываются вручную, и кэширует на 5 минут только во вкладке сайта.
- Файл обновления скачивается только после нажатия «Установить», лежит во временной папке приложения и удаляется после установки.
- Резервное копирование данных приложения в облако и перенос на другое устройство отключены.

## Удаление данных

- «Выйти из аккаунта» удаляет cookies, хранилище и кеш WebView, в том числе данные окна ссылок, отчёты об успеваемости, сохранённое расписание, расписание экзаменов и итоги журнала, зашифрованные логин и пароль и PIN-код; напоминания и фоновая проверка оценок снимаются. Язык и другие настройки остаются.
- «Файл для сообщения об ошибке» в настройках сохраняет в «Загрузки» только версии приложения, Android и WebView, размер экрана и настройки приложения (да/нет у сохранённого входа, PIN-кода и паузы). Логина, пароля, cookies, адресов страниц и оценок в нём нет; файл остаётся у вас, пока вы сами его не отправите.
- «Удалить данные и войти заново» на экране PIN-кода (если код забыт) удаляет то же самое.
- Удаление приложения удаляет все его данные; скачанные файлы остаются в «Загрузках».

## Разрешения

Интернет и состояние сети нужны для работы сайта, уведомления для прогресса загрузок, напоминаний о парах и сообщений о новых оценках, фоновая служба для загрузок, запуск после перезагрузки телефона, чтобы вернуть напоминания, виджет и проверку оценок, запись в память только на Android 7–9 для сохранения файлов в «Загрузки»; камера вызывается системным приложением только при выборе «Сделать фото» для вложения; установка приложений нужна только для обновления самого Univer и разрешается вами отдельно.
